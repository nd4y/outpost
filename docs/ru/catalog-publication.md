# Ограниченная публикация каталога

[English](../en/catalog-publication.md)

Источник отправляет подписанный каталог после надёжного сохранения зашифрованных объектов на приёмнике. Получение каталога ещё не делает поколение полным. Приёмник материализует и проверяет весь набор, сохраняет checkpoint проверки, затем публикует полное поколение и возвращает связанную с ним квитанцию. Источник сохраняет операцию до проверки и записи этой квитанции.

Один обычный шаг публикации через HTTPS теперь обрабатывает не более 8 МиБ данных и не более 256 объектов. Это соответствует максимальному размеру одного загружаемого объекта. Worker с промежуточным хранением сохраняет прежнее ограничение в один объект. Незавершённый ответ имеет код HTTP 202; источник продолжает тот же подписанный каталог через аутентифицированную подсказку продолжения. Срок запроса источника в 30 секунд, подписанные полномочия, проверка полного набора и окончательное чтение данных не изменены.

## Сбой и проверка причины

Прежний отдельный приёмник мог обрабатывать 256 МиБ до сохранения checkpoint проверки. В неудачном физическом прогоне на 100 ГиБ первая выбранная порция составляла ровно 35 объектов и 263980668 байт. При таймауте каталогового запроса были надёжно сохранены именно эти 35 объектов; checkpoint проверки и полного поколения не было. В промежуточное хранилище уже поступило 107395477507 байт тел запросов с исходными объектами. Это таймаут запроса после примерно десяти часов передачи, а не истечение общего срока теста в 36 часов. OOM и swap не было, но память многократно достигала лимита; запас памяти не подтверждён.

`TestCatalogDeadlineBoundsAndReopenedVerificationProgress` использует настоящий аутентифицированный HTTP и два набора по 24 МиБ. В обоих случаях срок тестового запроса составляет пять секунд. Управляемая остановка сохранения начинается, когда один запрос материализует более 8 МиБ, и заканчивается только при отмене этого настоящего HTTP-запроса. Явно заданный прежний пакет воспроизводит таймаут до записи checkpoint. Ограниченный пакет по умолчанию возвращает сохранённый частичный прогресс до истечения срока. Оба набора повторно открывают сессию и реплику, завершают исходный каталог и восстанавливают каждый байт. Частичное поколение не должно отображаться полным. Прежний контроль с пропорциональной задержкой сначала упал на старом production-параметре, затем прошёл с уменьшенным пакетом в обычной сборке, но оказался чувствителен к накладным расходам race. Его неудачный race-прогон сохранён. Управляемая остановка устраняет эту неоднозначность; в production задержка не добавляется.

Это подтверждает механизм взаимодействия пакета со сроком запроса и его исправление. Проверка не устанавливает единственную аппаратную причину исходной задержки диска и не доказывает успешный полный масштаб. Прогон на 100 ГиБ и независимые потребители в чистом окружении должны пройти отдельно на исправленных исходниках.

## Сохранённое состояние теста

Явно включаемый тест масштаба сохраняет каталог неудачного прогона. Теперь он также записывает с fsync закрытый синтетический контекст с исходными идентификаторами и bootstrap. Это предотвращает потерю закрытого ключа приёмника при завершении только тестового процесса. Контекст должен оставаться на допущенном тестовом томе с закрытыми правами; его нельзя выгружать с логами или публичными доказательствами. Перед успешным независимым восстановлением он удаляется вместе с исходником, runtime и файлами рабочих ключей. Сохранённый контекст сам по себе не подтверждает готовую команду продолжения теста.

Тест допускает не более трёх вызовов той же устойчивой операции источника при недоступности транспорта или таймауте отдельного запроса, как исполняемый цикл источника. Каждая неудачная попытка записывается, все полученные тела запросов учитываются вместе. Для получения успешного результата тест не продлевает полномочия, не меняет intent или срок запроса и не сбрасывает учёт трафика. Ошибки аутентификации и другие ошибки немедленно останавливают прогон. Сохраняются бюджет источника 2 ГиБ, изменение 8 МиБ, предел тел запросов с изменениями 128 МиБ и отсутствие файлового payload при неизменном содержимом.
