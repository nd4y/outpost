# Contributing

Read the [standard guide](docs/en/development-standard.md), [project passport](docs/en/project.md), [specification](docs/en/specification.md) and [roadmap](docs/en/roadmap.md).

Use a branch and pull request, meaningful changes to both README files and both documentation languages, pinned checks, secret scanning and relevant behavioral verification. The owner merges. Commands and scope are in [AGENTS.md](AGENTS.md).

Implementation must resolve G1-G3 without weakening requirements. Do not attach real backup data or infrastructure credentials to issues, pull requests or fixtures.

# Участие в проекте

Прочитайте [руководство стандарта](docs/ru/development-standard.md), [паспорт](docs/ru/project.md), [ТЗ](docs/ru/specification.md) и [этапы](docs/ru/roadmap.md).

Работайте в ветке и PR с содержательными правками обоих README и документации двух языков, закреплёнными проверками, поиском секретов и проверкой поведения. Merge выполняет владелец. Команды и границы указаны в [AGENTS.md](AGENTS.md).

До основной реализации нужно пройти G1-G3 без ослабления требований. Реальные копии и инфраструктурные секреты не включаются в задачи, PR и фикстуры.
