# Security policy

This project is in the design and prototype stage. No production backup or storage release is supported yet. Never use it as the only copy of data.

Use GitHub private vulnerability reporting when available. Otherwise contact the owner through their GitHub profile before sharing sensitive details. Do not post credentials, recovery kits, payloads, private topology or an exploit with private data in public issues. Ordinary non-sensitive design defects may be reported in Issues.

The owner assesses impact, mitigation and disclosure timing. No response-time SLA is promised at this stage. Revoke a leaked credential; removing it from Git alone is insufficient.

# Политика безопасности

Проект находится на стадии проектирования и прототипов. Поддерживаемого выпуска для рабочих резервных копий пока нет. Его нельзя использовать как единственную копию данных.

Используйте приватное сообщение об уязвимости на GitHub, когда оно доступно. Иначе сначала свяжитесь с владельцем через его профиль GitHub. Не публикуйте credentials, recovery kit, содержимое копий, приватную топологию и пример эксплуатации с закрытыми данными. Обычные замечания без чувствительных сведений можно создавать в Issues.

Владелец определяет влияние, меры защиты и срок раскрытия. SLA ответа на этой стадии не установлен. Опубликованный секрет необходимо отозвать; одного удаления из Git недостаточно.
